Hardware blocks

Power block

Voltage regulation, current safety, and brownout-aware design for small embedded miners and sensors.

IO block

Status LEDs, UART console, and a compact control surface for configuration and debug output.

Network block

Wi-Fi setup, pool credential storage, and lightweight transport handling for job polling.

Telemetry block

Share counts, temperatures, reconnect counters, and timing data for operations visibility.

Signal map

  • GPIO: route LEDs, button inputs, and optional buzzer feedback.
  • UART: serial debug and flash-time logging.
  • I2C/SPI: optional sensors for temperature, power, or fan control.
  • Wi-Fi: pool job fetch and result submission.
  • Timer: periodic status sampling and watchdog-safe housekeeping.

Workflow

  • Boot into a safe mode that confirms power, network, and storage readiness.
  • Load the miner profile and sync configuration with the ESP32 control plane.
  • Connect to the pool, decode incoming work, and prepare the nonce window.
  • Track hashes, shares, and rejects while keeping the UI responsive.
  • Surface metrics back to the repository dashboard via linked pages and reports.
