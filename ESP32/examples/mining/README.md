# Mining Examples

| Path | Purpose |
|------|---------|
| `stratum_client.ino` | Minimal ESP32 Wi-Fi pool client that shows job polling, reconnects, and share submission flow |

## Notes

- These examples are educational and keep the control flow small.
- They are intended to sit beside the repository's mining pages, not replace them.
