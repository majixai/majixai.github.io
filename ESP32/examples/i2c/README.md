# I2C Examples

| Path | Purpose |
|------|---------|
| `i2c_scan.ino` | Scan the bus and report detected I2C addresses |
| `i2c_sensor_probe.ino` | Read a generic register pair from an I2C peripheral |

## Notes

- The scan example is useful for bring-up and wiring verification.
- The probe example keeps the register flow small and easy to adapt.
