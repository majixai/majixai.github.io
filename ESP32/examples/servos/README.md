# Multiple Servo Examples

| Path | Purpose |
|------|---------|
| `multi_servo_sweep.ino` | Drive several servos from native PWM channels |
| `servo_pca9685_i2c.ino` | Drive multiple servos through a PCA9685 I2C controller |

## Notes

- The native PWM example is the simplest way to validate multiple outputs.
- The PCA9685 example shows how servo expansion and I2C fit together.
