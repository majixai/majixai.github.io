    Settings

    Webhook URLs are optional. When empty, the sidebar falls back to direct Yahoo Finance requests.

    Instructions
    Webhook flow
    1. Set the yfinance webhook URL in Settings if you want an external fetcher.
    2. Use the DB query webhook when you want the sidebar to hit a SQL/API service.
    3. If those URLs are empty, the sidebar falls back to direct Yahoo Finance chart requests.
    Chart inputs
    • Toggle indicators to build the stack used in the chart payload.
    • Pattern toggles control the recognition list shown below the chart.
    • Any change in the control surface can trigger a fresh chart request.
    Example webhook payload
    { "action": "yfinance_pull", "ticker": "SPY", "period": "1mo", "interval": "1d", "indicators": ["sma", "macd", "rsi"], "patterns": ["trend", "breakout"] }
    DB query payload
    { "action": "db_query", "database": "watchlist", "sql": "SELECT * FROM signals ORDER BY created_at DESC LIMIT 100", "limit": 100 }
