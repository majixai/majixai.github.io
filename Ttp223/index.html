Control blocks

  • Touch block: capacitance thresholding, trigger detection, and de-bounce behavior.
  • Wake block: low-power entry, wake-on-touch, and safe resume sequencing.
  • IO block: output signaling, LEDs, and MCU-side input handling.
  • Telemetry block: press counts, false-trigger counts, and state transitions.
  • Audit block: router/hash checks for provenance, page lineage, and control integrity.

Bring-up sequence

  • Verify power, ground, and touch pad wiring.
  • Confirm the default output state before exposing the sensor to the MCU.
  • Adjust sensitivity or threshold settings for the touch surface in use.
  • Run a short touch loop and confirm the output stays stable through repeated taps.
  • Escalate to recovery mode if wake or false-trigger checks fail.

Operational rules

  • Prefer stable touch surfaces and short wiring paths.
  • Keep threshold changes visible and documented.
  • Keep fallback access through serial or browser controls.
  • Mirror terminology with the ESP32 page for shared control semantics.
  • Keep the Ttp223 page linked from the circuit hub and control stack.
