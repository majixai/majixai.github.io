# Bitcoin Miner KiCad Assets

This directory contains the KiCad netlist for the 1 TH/s pool miner concept.

## Files

- `1TH_Miner.net` — master netlist for the ESP32-C3, level shifter, thermal controller, buck controller, and BM1366 ASIC chain

## Usage

Import `1TH_Miner.net` into KiCad PCB Editor via **File → Import → Netlist**.
